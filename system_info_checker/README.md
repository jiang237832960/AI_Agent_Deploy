# 系统环境检测

检测 Windows 系统的详细信息，包括操作系统版本、CPU、显卡、内存、硬盘等硬件信息。

## 功能特点

- 检测 Windows 版本（Windows 10/11 等）
- 检测系统架构（32位/64位）
- 检测 CPU 型号、核心数、线程数、频率
- 检测显卡信息和显存大小
- 检测内存总量和使用情况
- 检测硬盘各分区容量和使用情况

## 工具列表

| 脚本 | 说明 |
|------|------|
| start.py | 模块启动入口（菜单模式） |
| system_info.py | 系统硬件信息检测 |
| memory_checker.py | 内存使用情况详细分析 |

## 使用方法

### 方式一：通过主程序启动

```bash
# 从项目根目录
python main.py -m system_info

# 直接运行系统检测
python main.py -m system_info -- -a system

# 直接运行内存分析
python main.py -m system_info -- -a memory
```

### 方式二：独立运行

```bash
# 菜单模式
python scripts/start.py

# 系统信息检测
python scripts/system_info.py

# 内存使用情况检测
python scripts/memory_checker.py
```

### 方式三：批处理文件

双击运行：
- `scripts/system_info.bat` - 系统硬件检测
- `scripts/memory_checker.bat` - 内存详细分析

## 常见问题

### Q: 检测不到显卡信息？

A: 部分笔记本的核显可能显示为 "Intel(R) UHD Graphics"，这是正常现象。

### Q: 硬盘容量显示不准确？

A: 这是由于硬盘厂商和操作系统对 GB 的计算方式不同（1000 vs 1024），属于正常现象。

### Q: 为什么任务管理器中进程内存加起来与系统显示的使用率不匹配？

A: 这是正常现象。系统内存使用包括：
1. 用户进程内存
2. 系统内核/缓存（不可见但占用内存）
3. 进程间共享内存（多个进程共享 DLL 等）

使用 `memory_checker.py` 可以更清晰地查看各项内存占用。
