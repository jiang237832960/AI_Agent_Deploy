# Everything 工具说明

本文件夹用于存放 Everything 便携版工具。

## 获取方法

### 方法一：自动下载（推荐）

运行同目录下的 `download_everything.bat` 脚本，它会自动下载 Everything 便携版。

### 方法二：手动下载

1. 访问 [Everything 官网](https://www.voidtools.com/zh-cn/downloads/)
2. 下载 "Everything" 的 "Portable"（便携版）
3. 解压后将以下文件放到本目录：
   - `Everything.exe` - 主程序
   - `es.exe` - 命令行搜索工具

## 文件说明

- `Everything.exe` - Everything 主程序（用于建立索引）
- `es.exe` - Everything 命令行版本（用于脚本调用搜索）

## 注意事项

- 首次运行 Everything.exe 后，它会自动建立全盘索引
- 索引完成后，使用文件搜索功能即可获得极速体验
- 便携版不会修改系统注册表，可以随时删除
