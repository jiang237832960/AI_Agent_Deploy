## 标准化启动脚本设计方案

### 项目子模块分析
项目包含4个独立子模块：
1. **system_info_checker** - 系统环境检测
2. **dev_env_setup** - 开发环境配置
3. **github_accelerator** - GitHub加速
4. **file_search** - 文件搜索

### 设计方案

#### 1. 创建通用启动框架 (`core/launcher.py`)
- 版本信息管理
- 依赖检查机制
- 环境配置加载
- 参数解析与传递
- 错误处理与日志
- 启动状态反馈

#### 2. 为每个子模块创建启动脚本
每个子模块将拥有标准化的 `start.py` 和 `start.bat`：
- `system_info_checker/scripts/start.py`
- `dev_env_setup/scripts/start.py`
- `github_accelerator/scripts/start.py`
- `file_search/scripts/start.py`

#### 3. 创建主启动脚本 (`main.py` / `main.bat`)
- 统一入口管理所有子模块
- 菜单式选择启动
- 支持命令行参数直接启动指定模块

#### 4. 启动脚本核心功能
```
┌─────────────────────────────────────┐
│  启动脚本核心功能                    │
├─────────────────────────────────────┤
│  1. 版本信息显示                    │
│  2. Python环境检测                  │
│  3. 依赖包检查                      │
│  4. 配置文件加载                    │
│  5. 参数解析与传递                  │
│  6. 错误处理与恢复                  │
│  7. 启动状态反馈                    │
│  8. 日志记录                        │
└─────────────────────────────────────┘
```

#### 5. 文件结构
```
AI_Agent_Deploy/
├── main.py                    # 主启动脚本
├── main.bat                   # 主启动脚本(批处理)
├── core/
│   └── launcher.py            # 通用启动框架
├── config/
│   └── settings.json          # 全局配置
├── system_info_checker/
│   └── scripts/
│       └── start.py           # 子模块启动脚本
├── dev_env_setup/
│   └── scripts/
│       └── start.py
├── github_accelerator/
│   └── scripts/
│       └── start.py
└── file_search/
    └── scripts/
        └── start.py
```

#### 6. 使用方式
```bash
# 方式1：主菜单
python main.py

# 方式2：直接启动指定模块
python main.py --module system_info
python main.py --module github_accelerator --action check

# 方式3：批处理方式
main.bat
main.bat system_info
```

4. 创建 `main.py` 主启动脚本
