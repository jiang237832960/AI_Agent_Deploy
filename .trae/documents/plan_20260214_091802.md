# OpenClaw Windows 桌面软件改造计划

## 项目位置

**新建文件夹**：`D:\openclaw-desktop\`

## 目标

将 OpenClaw 开源项目改造成 Windows 桌面应用程序，使用 Electron 框架，实现：

* 首次运行安装向导（类似常规桌面软件）

* 启动软件即自动启动服务

* 内置完整 GUI 界面（100% 移植 OpenClaw Control UI）

* **根据填写的 API Key 和供应商自动获取可用模型列表**

* **随时可访问的配置界面**（安装完成后仍可随时修改 API Key 等配置）

* 支持系统托盘运行

* 支持开机自启动

## 技术方案

### 核心框架

* **Electron**：成熟的跨平台桌面应用框架

* **Node.js 22+**：OpenClaw 的运行时要求

* **electron-builder**：打包成 Windows 安装包

### GUI 界面功能（完整移植 OpenClaw Control UI）

| 页面                 | 功能描述                                             |
| ------------------ | ------------------------------------------------ |
| **Chat**           | 与 AI 助手聊天，发送/中断消息，实时工具调用显示                       |
| **Channels**       | WhatsApp/Telegram/Discord/Slack 等渠道状态、QR 登录、配置管理 |
| **Instances**      | 实例存在列表和刷新                                        |
| **Sessions**       | 会话列表，单会话 thinking/verbose 配置                     |
| **Cron jobs**      | 定时任务列表/添加/运行/启用/禁用，运行历史                          |
| **Skills**         | 技能状态、启用/禁用、安装、API Key 更新                         |
| **Nodes**          | 节点列表和能力展示                                        |
| **Exec approvals** | 网关/节点白名单编辑，执行策略配置                                |
| **Config**         | 查看/编辑配置文件，应用配置并验证，**API Key 管理 + 自动获取模型**        |
| **Debug**          | 状态/健康/模型快照，事件日志，手动 RPC 调用                        |
| **Logs**           | 网关日志实时 tail，筛选和导出                                |
| **Update**         | 包/git 更新和重启                                      |

### 模型自动获取功能

* **选择供应商**：Anthropic / OpenAI / Ollama / Azure OpenAI

* **填写 API Key**：用户输入密钥

* **自动获取模型**：调用对应供应商 API 获取可用模型列表

* **选择模型**：从下拉列表中选择具体模型

### 配置访问方式

1. **安装向导**：首次安装时引导配置
2. **托盘菜单**：右键 → "设置/配置"
3. **顶部导航**：导航栏进入 Config 页面
4. **快捷键**：支持快速打开配置

### 实现步骤

#### 第一阶段：项目初始化

1. 在 `D:\openclaw-desktop\` 创建 Electron 项目结构
2. 配置 package.json 和依赖
3. 设置 Electron 主进程和渲染进程

#### 第二阶段：安装向导

* 环境检测 → 选择供应商 → 填写 API Key → **自动获取模型** → 渠道配置 → 完成

#### 第三阶段：核心功能集成

1. 集成 OpenClaw 核心代码
2. 主进程中运行 Gateway 服务（端口 18789）
3. 嵌入本地 Web Server
4. IPC 通信机制

#### 第四阶段：完整 GUI 开发（12 个页面）

1. Chat / Channels / Instances / Sessions / Cron / Skills / Nodes / Approvals / **Config（含模型获取）** / Debug / Logs / Update

#### 第五阶段：桌面特性

* 托盘功能 / 开机自启动 / 最小化到托盘 / 全局快捷键

#### 第六阶段：打包发布

* electron-builder 配置

* 嵌入 Node.js 运行时

* 生成 .exe 安装包
